# Vorvex Foundation v1

Foundation v1 freezes the Mission 2 interaction and design foundation.

## Permanent interaction rules

- Vorvex is one continuous full-screen environment. Worlds reorganize within it; they do not become conventional pages.
- Every spatial financial object uses the same grammar: name above, icon centred, value or status below.
- The Universe remains visually dominant. Supporting information appears only after travel settles and stays compact.
- Closing a supporting surface does not change navigation depth. Visible parent objects, breadcrumbs, and the Vorvex logo always travel outward predictably.
- Needs Attention asks for the smallest useful number of decisions. Repeated patterns lead; individual transactions come last.
- Confirm saves atomically, preserves Undo, and advances automatically. Change brings the correction controls into focus.
- Recently Understood is the searchable correction history. Corrections replace prior understanding without duplicating transactions.
- Empty, non-actionable product sections remain hidden.
- Founder-facing language is plain English. Financial values lead the hierarchy; metadata remains readable and quiet.
- New work must preserve canonical data, ingestion, encryption, provenance, and calculation boundaries.

Broad visual redesign is frozen after this document. Subsequent work should extend these rules rather than replace them.

## Next product phase

The first post-foundation mission should be **Cash + Credit + Transaction Intelligence**: make daily cash position, credit obligations, transaction understanding, and recommended action completely useful as one connected module.
